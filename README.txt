Trace The Breach: The TechNova Incident (Offline Game)

How to run:
1) Extract the zip.
2) Open index.html in Chrome/Edge/Firefox (double-click).

What it contains:
- Briefing
- Evidence Hub (6 artefacts)
- Suspects board
- Mini-Quiz (3 questions)
- Accusation screen that grades your conclusion
- Notebook checklist + notes (saved in browser localStorage)

Tip:
- Open Evidence Hub first, view all artefacts, then attempt accusation.
