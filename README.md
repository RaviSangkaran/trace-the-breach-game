Trace The Breach: The TechNova Incident
Interactive Digital Forensics Investigation Game
 Overview

Trace The Breach: The TechNova Incident is an interactive, browser-based digital forensic investigation game developed using HTML, CSS, and JavaScript.

The game simulates a real-world cybersecurity incident where players take on the role of a digital forensic analyst, tasked with analysing evidence, reconstructing attack timelines, and identifying the responsible suspect.

This project is designed to bridge the gap between theoretical knowledge and practical application by providing a hands-on forensic investigation experience.

 Objectives
Analyse digital evidence from multiple sources
Identify Indicators of Compromise (IoCs)
Correlate logs and artefacts to reconstruct events
Determine the attacker and method used
Apply structured forensic methodology (Collection → Examination → Analysis → Reporting)
 Features
 Case briefing with realistic cybercrime scenario
 Evidence Hub with multiple digital artefacts
 Suspect analysis board
 Interactive forensic quiz
 Final accusation system with automatic grading
 Notebook checklist + notes (saved using browser localStorage)
 Fully offline browser-based gameplay (no installation required)
 Evidence Included

The game provides realistic forensic artefacts such as:

 Phishing email
 Login / VPN logs
 File access records
 USB activity logs
 Browser history
 Metadata and behavioural indicators

Players must analyse and correlate these artefacts to uncover the full attack chain.

 Learning Outcomes

This game helps users develop:

Critical thinking and analytical reasoning
Digital forensic investigation skills
Log and metadata interpretation
Timeline reconstruction ability
Cybersecurity awareness and decision-making
